   - **Section 6.4.4 (Integrity Algorithms)**: Mandates that null integrity (`nia0`) **must not** be used for any DRB or SRB.
   - **Section 6.4.4 (DRB Integrity)**: Requires integrity protection for all DRBs unless explicitly exempted (e.g., for specific services like emergency calls).

2. **O-RAN WG4 Security Requirements v7.0**
   - **Section 5.2.2 (Ciphering and Integrity Algorithms)**: Prohibits the use of null ciphering (`nea0`) and null integrity (`nia0`) in O-RAN-compliant deployments.
   - **Section 5.2.3 (DRB Security)**: Requires integrity protection for all DRBs unless explicitly justified by a valid use case (not present in this config).
