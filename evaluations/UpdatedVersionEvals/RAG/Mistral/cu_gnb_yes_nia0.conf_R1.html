Status: Non-Compliant
Compliance Assessment Summary

The configuration file violates 3GPP security requirements for integrity protection of Data Radio Bearers (DRBs). Specifically, the integrity algorithm list includes 'nia0', which is explicitly prohibited by 3GPP for DRBs when integrity protection is Required. The ciphering algorithms configuration is compliant with 3GPP requirements as 'nea0' is not prioritized and 'drb_ciphering' is enabled.

Violation Details
1. Use of Prohibited Integrity Algorithm (nia0) for DRBs
Critical

Non-Compliant Value: ( "nia0", "nia2", "nia1" )

Fix: Remove 'nia0' from the integrity_algorithms list and ensure only 'nia1', 'nia2', or 'nia3' are prioritized.

Reference: 3GPP TS 33.501 Annex D, 3GPP TS 33.523 Clause 5.2.2.1.5

Specification Text:

3GPP TS 33.501, Annex D, explicitly prohibits the use of 'nia0' for Data Radio Bearers (DRBs). The SMF Integrity Policy is set to 'Required', meaning integrity protection must be enforced using a valid algorithm.
