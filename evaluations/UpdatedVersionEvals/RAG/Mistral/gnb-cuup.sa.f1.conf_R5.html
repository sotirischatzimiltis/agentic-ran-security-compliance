Security Compliance Report

File: gnb-cuup.sa.f1.conf
Function: CU-UP
Status: Non-Compliant
Compliance Assessment Summary

The CU-UP configuration file is non-compliant due to missing or explicitly disabled security parameters for the F1-U interface. Specifically, the configuration does not explicitly enable IPSec, integrity protection, confidentiality protection, or replay protection for the F1-U interface, which are required based on the SMF policies (Integrity=Required, Confidentiality=Required).

Violation Details
1. Missing IPSec Configuration for F1-U Interface
Critical

Non-Compliant Value: Not explicitly configured

Fix: Explicitly enable IPSec, configure integrity and encryption algorithms, and enable replay protection for the F1-U interface.

Reference: 3GPP TS 33.501 clause 9.8.2, O-RAN.WG11.TS.STS-R004-v11.00 clause 6.5

Specification Text:

3GPP TS 33.501 clause 9.8.2 mandates the use of IPsec ESP with IKEv2 for the F1-U interface, ensuring confidentiality, integrity, and replay protection. O-RAN.WG11.TS.STS-R004-v11.00 further reinforces this requirement.

2. Missing Integrity Protection Configuration for F1-U Interface
Critical

Non-Compliant Value: Not explicitly configured

Fix: Configure an integrity algorithm (e.g., aes-gcm) for the F1-U interface.

Reference: 3GPP TS 33.501 clause 9.8.2, 3GPP TS 33.523 clause 7.2.2.1.3

Specification Text:

3GPP TS 33.501 clause 9.8.2 and TS 33.523 clause 7.2.2.1.3 mandate integrity protection for the F1-U interface. SMF Integrity Policy is set to 'Required'.

3. Missing Confidentiality Protection Configuration for F1-U Interface
Critical

Non-Compliant Value: Not explicitly configured

Fix: Configure an encryption algorithm (e.g., aes-256) for the F1-U interface.

Reference: 3GPP TS 33.501 clause 9.8.2, 3GPP TS 33.523 clause 7.2.2.1.3

Specification Text:

3GPP TS 33.501 clause 9.8.2 and TS 33.523 clause 7.2.2.1.3 mandate confidentiality protection for the F1-U interface. SMF Confidentiality Policy is set to 'Required'.

4. Missing Replay Protection Configuration for F1-U Interface
High

Non-Compliant Value: Not explicitly configured

Fix: Enable replay protection for the F1-U interface.

Reference: 3GPP TS 33.501 clause 9.8.2

Specification Text:

3GPP TS 33.501 clause 9.8.2 mandates replay protection for the F1-U interface.
