Compliance Assessment Summary

The configuration specifies integrity_algorithms = ( "nia2", "nia0" ); and drb_integrity = "no". According to 3GPP TS 33.501, when the SMF Integrity Policy is set to Optional, it is not a violation to disable integrity protection. However, the use of 'nia0' (NULL integrity) for user data is not recommended and is only permitted if not activated. The configuration does not force the use of 'nia0'; therefore, there is no explicit violation. O-RAN documents confirm that support for these controls is mandatory for the vendor but optional for the operator, aligned with local/regional policy. No 3GPP or O-RAN requirements are breached with these settings in the provided context.
