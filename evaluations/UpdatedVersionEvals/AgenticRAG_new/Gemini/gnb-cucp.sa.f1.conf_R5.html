Security Compliance Report

File: gnb-cucp.sa.f1.conf
Function: gbn(CU-CP)
Status: Non-Compliant
Compliance Assessment Summary

The gNB (CU-CP) configuration is non-compliant due to the inclusion of the null integrity algorithm (NIA0) in the preferred integrity algorithms list, which violates 3GPP requirements for RRC signalling integrity protection. The corrected configuration addresses this by removing NIA0.

Violation Details
1. Null Integrity Algorithm (NIA0) in Preferred List
High

Non-Compliant Value: ( "nia2", "nia0" )

Fix: integrity_algorithms = ( "nia2" );

Reference: 3GPP TS 33.501, clause 5.3.3

Specification Text:

The gNB shall integrity-protect RRC signalling messages with an algorithm different from NIA0. NIA0 shall be disabled unless unauthenticated emergency sessions are a regulatory requirement.

Reflection Agent Analysis
REVISION NEEDED: YES

The Compliance Agent missed a security violation related to the use of NEA0 ciphering algorithm. While the corrected_config appropriately removes NEA0, this issue was not identified in the violations list. NEA0 provides no security and should be flagged as a violation based on 3GPP TS 33.501, Annex D.1.
