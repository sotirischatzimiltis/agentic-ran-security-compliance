Security Compliance Report

File: cu_gnb.conf
Function: gNB(CU)
Status: Non-Compliant
Compliance Assessment Summary

The gNB(CU) configuration file contains critical security violations related to the use of null ciphering (nea0) and null integrity (nia0) algorithms, as well as disabling DRB integrity protection without explicit SMF approval. These violate 3GPP TS 33.501 and TS 33.523 requirements.

Violation Details
1. Use of Null Ciphering Algorithm (nea0) Without Explicit SMF Approval
Critical

Non-Compliant Value: ("nea0")

Fix: Remove 'nea0' from the list of ciphering algorithms or ensure SMF explicitly permits its use.

Reference: TS 33.501 [3], clause 5.3.2, TS 33.523 [3], clause 6.2.2.1.7

Specification Text:

The gNB shall not use the null ciphering algorithm (nea0) unless explicitly permitted by the SMF security policy.

2. Use of Null Integrity Algorithm (nia0) Without Explicit SMF Approval
Critical

Non-Compliant Value: ("nia2", "nia0")

Fix: Remove 'nia0' from the list of integrity algorithms or ensure SMF explicitly permits its use.

Reference: TS 33.501 [3], clause 6.7.3.0, TS 33.511 [2], clause 4.2.2.1.1

Specification Text:

The gNB shall not use the null integrity algorithm (nia0) unless explicitly permitted by the SMF security policy.

3. Disabling DRB Integrity Protection Without Explicit SMF Approval
Medium

Non-Compliant Value: "no"

Fix: Ensure SMF explicitly permits disabling DRB integrity protection or set 'drb_integrity = "yes"'.

Reference: TS 33.501 [3], clause 6.6.2, TS 33.501 [3], clause 6.10.4

Specification Text:

The gNB shall not disable DRB integrity protection unless explicitly permitted by the SMF security policy.
