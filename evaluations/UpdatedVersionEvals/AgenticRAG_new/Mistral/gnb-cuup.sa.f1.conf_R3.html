Security Compliance Report

File: gnb-cuup.sa.f1.conf
Function: gNB(CU-UP)
Status: Non-Compliant
Compliance Assessment Summary

The configuration file for gNB(CU-UP) is non-compliant with 3GPP security requirements. Critical security parameters for IPsec on the E1, F1-U, and NG/NGU interfaces are missing. These parameters are mandatory for confidentiality, integrity, and replay protection as per 3GPP TS 33.501.

Violation Details
1. Missing IPsec Configuration for E1 Interface
Critical

Non-Compliant Value: Not configured

Fix: Add SECURITY_PROTOCOL = "IPSEC_OR_DTLS"; IPSEC_ENABLED = "true"; IPSEC_POLICY = "ESP_TUNNEL_MODE"; and IPSEC_IKEV2_AUTH = "CERTIFICATE_BASED"; to the E1_INTERFACE configuration.

Reference: 3GPP TS 33.501, Clause 9.8.3

Specification Text:

IPsec with ESP tunnel mode and certificate-based IKEv2 authentication is mandatory for the E1 interface as per 3GPP TS 33.501, Clause 9.8.3.

2. Missing IPsec Configuration for F1-U Interface
Critical

Non-Compliant Value: Not configured

Fix: Add IPSEC_ENABLED = "true"; IPSEC_POLICY = "ESP_TUNNEL_MODE"; and IPSEC_IKEV2_AUTH = "CERTIFICATE_BASED"; to the F1-U configuration.

Reference: 3GPP TS 33.501, Clause 5.3.9, 3GPP TS 33.501, Clause 9.8.2

Specification Text:

IPsec with ESP tunnel mode and certificate-based IKEv2 authentication is mandatory for the F1-U interface as per 3GPP TS 33.501, Clause 5.3.9 and 9.8.2.

3. Missing IPsec Configuration for NG and NGU Interfaces
Critical

Non-Compliant Value: Not configured

Fix: Add IPSEC_ENABLED = "true"; IPSEC_POLICY = "ESP_TUNNEL_MODE"; and IPSEC_IKEV2_AUTH = "CERTIFICATE_BASED"; to the NETWORK_INTERFACES configuration.

Reference: 3GPP TS 33.501, Clause 9.8.3

Specification Text:

IPsec with ESP tunnel mode and certificate-based IKEv2 authentication is mandatory for NG and NGU interfaces as per 3GPP TS 33.501, Clause 9.8.3.
