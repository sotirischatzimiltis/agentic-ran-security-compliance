Security Compliance Report

File: gnb-cuup.sa.f1.conf
Function: gNB(CU-UP)
Status: Non-Compliant
Compliance Assessment Summary

The gNB(CU-UP) configuration is non-compliant with 3GPP security requirements. Critical violations include missing IPsec/DTLS protection for the E1 interface, NGU interface, and SCTP transport layer. These omissions expose control plane and user plane traffic to eavesdropping, tampering, and replay attacks.

Violation Details
1. Missing IPsec/DTLS for E1 Interface
Critical

Non-Compliant Value: No security configuration

Fix: Add IPsec or DTLS configuration to the E1_INTERFACE block.

Reference: 3GPP TS 33.501, clause 5.3.10, 3GPP TS 33.501, clause 9.8.3

Specification Text:

The E1 interface between CU-CP and CU-UP shall be confidentiality, integrity, and replay-protected using IPsec or DTLS as per 3GPP TS 33.501, clauses 5.3.10 and 9.8.3.

2. Missing IPsec for NGU Interface (User Plane)
Critical

Non-Compliant Value: No IPsec configuration

Fix: Add IPsec configuration to the NETWORK_INTERFACES block.

Reference: 3GPP TS 33.523, clause 6.2.2.1.4, 3GPP TS 33.523, clause 6.2.2.1.5

Specification Text:

The NGU interface shall be confidentiality, integrity, and replay-protected for user plane data as per 3GPP TS 33.501, clauses 5.3.9, 9.3, and 9.4.

3. Missing DTLS/IPsec for SCTP Transport
High

Non-Compliant Value: No DTLS or IPsec configuration

Fix: Add DTLS or IPsec configuration to the SCTP block.

Reference: 3GPP TS 33.501, clause 9.8.3

Specification Text:

SCTP associations shall be protected using DTLS or IPsec as per 3GPP TS 33.501, clause 9.8.3.
