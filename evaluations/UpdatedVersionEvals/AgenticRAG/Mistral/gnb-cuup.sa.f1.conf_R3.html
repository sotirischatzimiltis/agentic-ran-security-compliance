Compliance Assessment Summary

The CU-UP configuration file is non-compliant due to missing explicit security configurations for user plane integrity and confidentiality protection on the F1-U and E1 interfaces. While the SMF policies require both integrity and confidentiality, the configuration does not explicitly enforce these protections.

Violation Details
1. Missing User Plane Integrity and Confidentiality Protection for F1-U Interface
Critical

Non-Compliant Value: No explicit configuration for integrity and confidentiality protection

Fix: Explicitly configure IPsec with integrity, confidentiality, and replay protection for the F1-U interface in the NETWORK_INTERFACES section.

Reference: 3GPP TS 33.501, clause 9.8.2, 3GPP TS 33.523, clause 6.2.2.1.1, O-RAN.WG11.TR.Open-FH-Security.0-R004-v05.00, clause 4.4.2

Specification Text:

The F1-U interface must support confidentiality, integrity, and replay protection as specified in 3GPP TS 33.501, clause 9.8.2. SMF Integrity and Confidentiality Policies are set to 'Required'.

2. Missing Integrity and Confidentiality Protection for E1 Interface
Critical

Non-Compliant Value: No explicit configuration for integrity and confidentiality protection

Fix: Explicitly configure IPsec with integrity, confidentiality, and replay protection for the E1 interface in the E1_INTERFACE section.

Reference: 3GPP TS 33.501, clause 9.8.3, 3GPP TS 33.523, clause 6.2.2.1.3

Specification Text:

The E1 interface must support confidentiality, integrity, and replay protection as specified in 3GPP TS 33.501, clause 9.8.3. SMF Integrity and Confidentiality Policies are set to 'Required'.
