Security Compliance Report

File: gnb-cuup.sa.f1.conf
Function: CU-UP
Status: Non-Compliant
Compliance Assessment Summary

The CU-UP configuration file violates 3GPP and O-RAN security requirements for transport and application layer security. Specifically, the F1, E1, and NG-U interfaces lack mandatory IPsec and TLS configurations for integrity and confidentiality protection, which are required as per the SMF policies.

Violation Details
1. Missing IPsec Configuration for F1 Interface
Critical

Non-Compliant Value: Not Configured

Fix: Add IPsec configuration under the SCTP section for the F1 interface.

Reference: TS 33.501 clause 9.8.2, O-RAN.WG11.TR.ZTA-R004-v04.00 Table 7.2-1

Specification Text:

3GPP TS 33.501 clause 9.8.2 mandates the use of IPsec or DTLS for confidentiality, integrity, and replay protection on the F1 interface. O-RAN WG11 Table 7.2-1 also mandates IPsec for authenticity, confidentiality, and integrity on the F1 interface.

2. Missing TLS and IPsec Configuration for E1 Interface
Critical

Non-Compliant Value: Not Configured

Fix: Add TLS and IPsec configuration under the E1_INTERFACE section.

Reference: TS 33.501 clause 9.8.3, TS 33.501 clause 5.3.10

Specification Text:

3GPP TS 33.501 clause 9.8.3 mandates that the E1 interface shall support IPsec ESP and IKEv2 for confidentiality, integrity, and replay protection. Additionally, DTLS (TLS) shall be supported for mutual authentication, integrity, replay, and confidentiality protection.

3. Missing IPsec Configuration for NG-U Interface
Critical

Non-Compliant Value: Not Configured

Fix: Add IPsec configuration under the NETWORK_INTERFACES section for NG-U.

Reference: TS 33.501 clause 5.3.9, TS 33.523 clause 6.2.2.1.5, O-RAN.WG11.TS.STS-R004-v11.00 clause 22

Specification Text:

3GPP TS 33.501 clauses 5.3.9, 9.3, and 9.4 mandate confidentiality, integrity, and replay protection for user plane data over N3 (NG-U). O-RAN WG11 aligns with these requirements for O-CU-UP.
