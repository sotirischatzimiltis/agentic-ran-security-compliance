Security Compliance Report

File: gnb-cuup.sa.f1.conf
Function: CU-UP
Status: Non-Compliant
Compliance Assessment Summary

The CU-UP configuration file is non-compliant with 3GPP and O-RAN security requirements for integrity and confidentiality protection on the F1-U, E1, and NG-U interfaces. Specifically, the original configuration lacks explicit IPsec and SCTP protection mechanisms, which are required as per the SMF Integrity and Confidentiality policies (both marked as 'Required').

Violation Details
1. Missing IPsec Configuration for F1-U Interface
Critical

Non-Compliant Value: Not Configured

Fix: Add the following configurations under the F1-U interface: F1U_IPSEC_ENABLED = "true"; F1U_IPSEC_INTEGRITY_ALGORITHM = "AES-GCM"; F1U_IPSEC_CONFIDENTIALITY_ALGORITHM = "AES-GCM";

Reference: 3GPP TS 33.501 (Clause 9.8.2), O-RAN.WG11.TS.STS-R004-v11.00 (Clause 6.5)

Specification Text:

3GPP TS 33.501 (Clause 9.8.2) mandates that IPsec ESP with confidentiality, integrity, and replay protection shall be supported for the F1-U interface. SMF Integrity and Confidentiality policies are marked as 'Required'.

2. Missing IPsec Configuration for E1 Interface
Critical

Non-Compliant Value: Not Configured

Fix: Add the following configurations under the E1 interface: IPSEC_ENABLED = "true"; IPSEC_INTEGRITY_ALGORITHM = "AES-GCM"; IPSEC_CONFIDENTIALITY_ALGORITHM = "AES-GCM";

Reference: 3GPP TS 33.501 (Clause 9.8.3), O-RAN.WG11.TS.STS-R004-v11.00 (Clause 6.5)

Specification Text:

3GPP TS 33.501 (Clause 9.8.3) mandates that IPsec ESP with confidentiality, integrity, and replay protection shall be supported for the E1 interface. SMF Integrity and Confidentiality policies are marked as 'Required'.

3. Missing IPsec Configuration for NG-U Interface
Critical

Non-Compliant Value: Not Configured

Fix: Add the following configurations under the NETWORK_INTERFACES section: NGU_IPSEC_ENABLED = "true"; NGU_IPSEC_INTEGRITY_ALGORITHM = "AES-GCM"; NGU_IPSEC_CONFIDENTIALITY_ALGORITHM = "AES-GCM";

Reference: 3GPP TS 33.501 (Clause 6.6), O-RAN.WG11.TS.STS-R004-v11.00 (Clause 6.5)

Specification Text:

3GPP TS 33.501 (Clause 6.6) mandates that the NG-U interface must support confidentiality and integrity protection as per the SMF UP security policy. SMF Integrity and Confidentiality policies are marked as 'Required'.

4. Missing SCTP Integrity and Confidentiality Protection
High

Non-Compliant Value: Not Configured

Fix: Add the following configurations under the SCTP section: SCTP_INTEGRITY_PROTECTION = "enabled"; SCTP_CONFIDENTIALITY_PROTECTION = "enabled";

Reference: 3GPP TS 33.523 (Clause 5.2.2.1.3), O-RAN.WG11.TS.STS-R004-v11.00 (Clause 6.11.6)

Specification Text:

3GPP TS 33.523 (Clause 5.2.2.1.3) mandates that the SCTP protocol must support confidentiality and integrity protection for control plane interfaces. O-RAN security requirements also emphasize SCTP security.
