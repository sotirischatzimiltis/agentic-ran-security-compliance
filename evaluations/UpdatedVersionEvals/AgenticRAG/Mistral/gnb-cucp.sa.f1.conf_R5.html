Security Compliance Report

File: gnb-cucp.sa.f1.conf
Function: CU-CP
Status: Non-Compliant
Compliance Assessment Summary

The CU-CP configuration violates 3GPP security requirements for ciphering, integrity protection, and DRB integrity. Specifically: (1) Use of 'nea0' (null ciphering) is explicitly prohibited for confidentiality protection, (2) Use of 'nia0' (null integrity) is explicitly prohibited for RRC signalling, and (3) DRB integrity protection is explicitly disabled, which may violate SMF policies if UP integrity is required.

Violation Details
1. Null Ciphering Algorithm (nea0) is Explicitly Configured
Critical

Non-Compliant Value: ("nea0")

Fix: Remove 'nea0' from the ciphering_algorithms list and replace it with a secure algorithm (e.g., 'nea2').

Reference: 3GPP TS 33.501, Clause 5.3.2, 3GPP TS 33.501, Annex D

Specification Text:

3GPP TS 33.501 [5.3.2] mandates that the gNB shall support ciphering of user data and RRC signalling. The use of 'nea0' (null ciphering) violates this requirement as it provides no confidentiality protection.

2. Null Integrity Algorithm (nia0) is Explicitly Configured
High

Non-Compliant Value: ("nia2", "nia0")

Fix: Remove 'nia0' from the integrity_algorithms list.

Reference: 3GPP TS 33.501, Clause 5.3.3, 3GPP TS 33.501, Clause 6.7.3

Specification Text:

3GPP TS 33.501 [5.3.3] mandates that integrity protection must be used for RRC signalling and shall not use 'nia0' (null integrity) except for unauthenticated emergency calls.

3. DRB Integrity Protection is Explicitly Disabled
High

Non-Compliant Value: "no"

Fix: Set drb_integrity = "yes" to enable integrity protection for DRBs.

Reference: 3GPP TS 33.501, Clause 5.3.2, 3GPP TS 38.300, Clause 13.1, O-RAN.WG11.TS.STS-R004-v11.00, Clause 4.2.2.1.2

Specification Text:

3GPP TS 33.501 [5.3.2] states that integrity protection for user data (DRBs) is optional but must be enabled if the UP security policy (from SMF) requires it. 3GPP TS 38.300 [13.1] states that integrity protection for DRBs is optional but must be enabled for PDU sessions where UP integrity protection is required.
