### **Violations Found**

#### **1. Ciphering Algorithm (`nea0`)**
- **Specification Reference**:
  - **3GPP TS 33.501 V17.6.0, Clause 5.11.2**: Null ciphering (`nea0`) is **prohibited** for user data protection in 5G NR.
  - **O-RAN.WG4.Security Requirements**: Null ciphering (`nea0`) is **not allowed** for DRBs (Data Radio Bearers).
- **Security Risk**:
  - `nea0` provides **no encryption**, exposing user data to eavesdropping and tampering.
- **Fix Required**:
  - Remove `nea0` from the `ciphering_algorithms` list.
  - Replace with a **strong ciphering algorithm** (e.g., `nea2` or `nea3`).

#### **2. Integrity Algorithm (`nia0`)**
- **Specification Reference**:
  - **3GPP TS 33.501 V17.6.0, Clause 5.11.1.2**: Null integrity (`nia0`) is **prohibited** for DRBs and SRBs (Signaling Radio Bearers).
  - **O-RAN.WG4.Security Requirements**: Null integrity (`nia0`) is **not allowed** for any radio bearer.
- **Security Risk**:
  - `nia0` provides **no integrity protection**, allowing message tampering and replay attacks.
- **Fix Required**:
  - Remove `nia0` from the `integrity_algorithms` list.
  - Ensure `nia2` (128-NIA2) is the **highest priority** algorithm.

#### **3. DRB Integrity (`drb_integrity = "no"`)**
- **Specification Reference**:
  - **3GPP TS 33.501 V17.6.0, Clause 5.3.2**: Integrity protection is **mandatory** for DRBs in 5G NR.
  - **O-RAN.WG4.Security Requirements**: DRB integrity must be **enabled** to prevent tampering.
- **Security Risk**:
  - Disabling DRB integrity exposes user data to **tampering** and **replay attacks**.
- **Fix Required**:
  - Set `drb_integrity = "yes"`.

#### **4. SCTP Streams (`SCTP_INSTREAMS = 2`, `SCTP_OUTSTREAMS = 2`)**
- **Specification Reference**:
  - **3GPP TS 38.473 V16.2.0, Clause 4.1**: F1AP requires **at least 2 streams** for SCTP, but **O-RAN.WG4** recommends **at least 4 streams** for redundancy and load balancing.
- **Security Risk**:
  - Insufficient streams may lead to **SCTP stream exhaustion**, causing **Denial of Service (DoS)**.
- **Fix Required**:
  - Increase `SCTP_INSTREAMS` and `SCTP_OUTSTREAMS` to **4**.

#### **5. F1AP Port (`local_s_portc = 501`, `remote_s_portc = 500`)**
- **Specification Reference**:
  - **3GPP TS 38.472 V16.2.0, Clause 4.2**: F1AP **must** use **IANA-assigned port 38472** for SCTP.
- **Security Risk**:
  - Non-standard ports may **violate 3GPP compliance** and expose the system to **unauthorized access**.
- **Fix Required**:
  - Update `local_s_portc` and `remote_s_portc` to **38472**.
