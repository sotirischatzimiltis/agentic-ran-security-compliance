### **Violations Found**

#### **1. Lack of Security Protection for F1 Interface (Control and User Plane)**
- **Standard Reference**:
  - **3GPP TS 33.501, Clause 9.8.2** (F1 interface security mechanisms)
    - *"The F1 interface shall be protected using IPsec ESP or DTLS with mutual authentication, integrity, confidentiality, and replay protection."*
    - **Filename**: `ts_133501v180900p.pdf`
  - **ETSI TS 133 501, Clause M.3.3.2**
    - *"IKEv2 Pre-shared Secret Key (PSK) authentication shall be supported for F1 interface security."*
    - **Filename**: `ts_133501v180900p.pdf`

- **Security Risk**:
  - The F1 interface is exposed to **eavesdropping, tampering, and replay attacks** due to the absence of **IPsec, DTLS, or IKEv2** configuration.
  - **SCTP parameters alone do not provide cryptographic protection**.

- **Fix Required**:
  - **No explicit security parameters are present** in the configuration.
  - **Out-of-Scope Recommendation**: Add `IPsec`, `DTLS`, or `IKEv2` configuration for F1 interface protection.

#### **2. Lack of Security Protection for E1 Interface (Control Plane)**
- **Standard Reference**:
  - **3GPP TS 33.501, Clause 9.8.3**
    - *"The E1 interface shall be protected using IPsec ESP or DTLS with mutual authentication, integrity, confidentiality, and replay protection."*
    - **Filename**: `ts_133501v180900p.pdf`
  - **TS 33.523, Clause 6.2.2.1.3**
    - *"The E1 interface between CU-CP and CU-UP is confidentiality, integrity, and replay-protected as specified in TS 33.501, clauses 5.3.10."*
    - **Filename**: `TS 133 523 - V18.2.0.pdf`

- **Security Risk**:
  - The E1 interface is exposed to **control plane tampering, eavesdropping, and replay attacks** due to the absence of **IPsec or DTLS** configuration.

- **Fix Required**:
  - **No explicit security parameters are present** in the configuration.
  - **Out-of-Scope Recommendation**: Add `IPsec` or `DTLS` configuration for E1 interface protection.

#### **3. Lack of User Plane Security for NG-U and F1-U Interfaces**
- **Standard Reference**:
  - **3GPP TS 33.501, Clause 5.3.9, 9.3, 9.4**
    - *"The gNB supports confidentiality, integrity, and replay protection on the gNB DU-CU F1-U interface for user plane."*
    - **Filename**: `ts_138401v160300p.pdf`
  - **TS 33.523, Clause 6.2.2.1.4**
    - *"The transport of user data over N3 is integrity, confidentiality, and replay-protected."*
    - **Filename**: `TS 133 523 - V18.2.0.pdf`

- **Standard Reference**:
  - **O-RAN.WG11.TS.STS-R004, Clause 5.3.8.11.7**
